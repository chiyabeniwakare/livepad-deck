LIVEPAD DECK

プライバシーポリシー

制定日：2026年11月22日

LIVEPAD DECK（以下「本アプリ」）は、配信向けの効果音パッドとBGMプレイヤーです。本アプリは、利用者の情報を以下のとおり取り扱います。

1. 扱う情報

  • 本アプリに登録した音声ファイルと設定（パッドの割り当て、タブ名、BGMリスト、音量、テーマカラー、画面の配置など）
  • Googleドライブ内のファイル：Googleアカウントでログインした場合、本アプリはGoogleドライブへのアクセス権限（drive.file）を利用します。この権限で本アプリが扱えるのは、本アプリが作成したファイルと、利用者がファイル選択画面で自分で選んだファイルだけです。それ以外のファイルを閲覧・変更することはありません。
  • Googleアカウントの名前とメールアドレス：ログイン中のアカウントを画面に表示するために取得することがあります。

2. 利用目的

上記の情報は、音声ファイルと設定の保存・復元、および複数の端末で同じ内容を使えるようにする（同期する）ためだけに利用します。

3. 保存場所

  • 利用者本人のGoogleドライブ（「LIVEPAD DECK」フォルダ）
  • 利用者が使っている端末のブラウザの中（IndexedDB）

本アプリには作者が運営するサーバーはなく、これらの情報が作者に送信されることはありません。作者が利用者のファイルや設定を見ることもできません。

4. 第三者への提供

本アプリは、利用者の情報を第三者に提供・販売しません。広告や利用状況の解析ツールも使用していません。

なお、ログインとドライブへの保存にはGoogleのサービスを、画面の表示には文字や画面部品の配信サービス（Google Fonts など）を利用しています。これらのサービスにおける情報の取り扱いは、各サービスの規約に従います。

5. Googleユーザーデータの取り扱い

本アプリによるGoogle APIから受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に準拠します。

6. データの削除とアクセスの取り消し

  • ブラウザ内のデータ：本アプリの設定画面の「データ初期化」、またはブラウザのサイトデータの削除で消去できます。
  • Googleドライブのデータ：ドライブ内の「LIVEPAD DECK」フォルダを削除してください。
  • アクセス許可の取り消し：Googleアカウントの「サードパーティ製のアプリとサービス」から、本アプリへのアクセスをいつでも取り消せます。

7. このポリシーの変更

本ポリシーは、必要に応じて変更することがあります。変更した場合は、このページでお知らせします。

8. お問い合わせ

本アプリや本ポリシーに関するお問い合わせは、GitHub の Issues からお送りください。
