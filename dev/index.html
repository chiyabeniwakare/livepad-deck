設定・データ管理

テーマカラー
背景の色調

AUTO：iPhone・iPad・PCのダーク／ライトの設定に合わせて自動で切り替えます

OBS連携

OBSとつなぐ設定は、右上の OBS ボタンからも開けます

キーボード（SEパッド）

PCのキーボードでSEパッドを鳴らすときのキーの並び。NUMPAD はテンキー用です（テンキーのないPCは、USBのテンキーをつなぐと使えます）。この設定は端末ごとに保存されます

Ctrl+Z（Macは ⌘+Z）で、パッド・BGM・LAYOUT などの編集を元に戻せます。やり直しは Ctrl+Shift+Z か Ctrl+Y

DUCKの下げ幅
80%

MIXERのDUCKボタンを押している間、BGMを今の音量の何%にするか（例：BGM 70% で 80% の場合 → 56%）

保存と同期

登録した音声ファイル・パッド設定・BGMプレイリストはブラウザ内に自動保存されます。Googleでログインすると、Googleドライブの「LIVEPAD DECK」フォルダにも保存され、別の端末やブラウザのデータを消したあとでも、ログインするだけで元に戻せます。

※ iPhone・iPadのSafariは、しばらく開かないサイトのデータを消すことがあります。ホーム画面に追加して使うか、Googleでログインしてバックアップしておくのがおすすめです。

良いこと

画面が広くなるアドレスバーなどが消えて、パッドを大きく使えます
データが消えにくいSafariは、しばらく開かないサイトのデータを消すことがあります。ホーム画面から開けば消えません
すぐ開けるホーム画面のアイコンをタップするだけ

追加のしかた

  1. 画面右下の を押す下に があるときは、それを押して 3 へ
  2. 「共有」を押す
  3. 「その他」→「ホーム画面に追加」見当たらないときは、上にスクロール
  4. 「追加」を押す「Webアプリとして開く」はオンのまま
  1. 画面の上にある （共有）を押す
  2. 「その他」→「ホーム画面に追加」見当たらないときは、上にスクロール
  3. 「追加」を押す「Webアプリとして開く」はオンのまま
  1. このブラウザのメニューの「共有」から「ホーム画面に追加」を選ぶ
  2. 見つからないときは、このページを Safari で開いてから追加します

追加したら、ホーム画面の LIVEPAD のアイコンから開いてください

ホーム画面のアイコンから開くと、Safari とはデータの保存場所が別になります（Safari で入れた音は引き継がれません）。音を入れる前に追加しておくのがおすすめです。Googleでログインしていれば、ログインするだけで元に戻せます。
